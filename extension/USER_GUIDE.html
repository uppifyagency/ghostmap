1. Install (one time)

  1. Open Google Chrome.
  2. Go to chrome://extensions.
  3. Turn Developer mode ON (top right).
  4. Click Load unpacked.
  5. Choose the project’s extension folder.
  6. Pin Ghost Map Pro from Chrome’s puzzle icon.
  7. Open Google Maps.
  8. Click the Ghost Map icon → open the side panel.
After any update, open chrome://extensions and click Reload on Ghost Map Pro.

2. The big picture — 3 phases

PhaseNameWhat it does
1DiscoverFind businesses (Area Search or Monitor Maps)
2ExtractVisit websites and collect emails
3ExportDownload CSV, Markdown, or filtered Excel

Always use them in order for best results.

3. Understanding the numbers

What you seeWhat it means
Businesses FoundUnique companies saved
WebsitesHow many have a website URL
Email progress e.g. 12 / 19Progress for this email run (queued websites), not total businesses
Example: Area Search finds 100 businesses. Only 70 have websites. Email extraction will queue about 70 — not 100. That is normal.

4. Phase 1 — Discover

Area Search (whole city)

  1. Click Launch Area Search.
  2. Enter city (e.g. Melbourne, Australia).
  3. Set radius in km — maximum about 200. Do not use huge values like 15000.
  4. Enter keywords (one per line), e.g. roofing.
  5. Leave Turbo on; Parallel Tabs around 8 is a good start.
  6. Click Start Turbo Search and watch live progress.
Maps helper windows may open in the background. You should be able to keep working in other apps.

Monitor Maps (manual)

Search on Maps yourself → Start Monitoring → scroll results slowly → Stop. Good for small areas.

Extract Websites

Use when many businesses have no website yet. Click Extract Websites; use Pause if needed.

New city tip: Before Sydney after Melbourne, click Reset All first so old leads do not mix in.

5. Phase 2 — Extract emails

  1. Open the Extract tab.
  2. Click Start Extraction.
  3. Use Pause / Resume anytime — progress is kept.
  4. Use Retry Failed later for sites that blocked or timed out.

Not every website publishes an email. A rising “failed” count is often normal.

Tiny website windows may flash briefly. Ghost Map should not keep pulling focus back to Chrome while you work elsewhere.

What “Export xlsx filtered” puts in Excel

SheetWho is on it
DashboardSummary counts and categories
Owner LeadsWebsite + personal-looking email (e.g. john@…)
General LeadsWebsite + generic email (info@, sales@, admin@…)
Needs Follow-UpWebsite but no email yet
No WebsiteNo website URL
Duplicate LeadsSame phone, email, or website domain as a stronger lead
Example: You have 515 businesses. Click Export xlsx filtered. Excel opens with a Dashboard plus Owner / General / Follow-Up / No Website / Duplicates tabs — same logic as the offline “CSV → Excel Ledger” tool, built into Ghost Map.

Export CSV and Export MD still work exactly as before.

8. Example workflows

A) Full city list (most common)

  1. Reset All (if new city).
  2. Area Search — city + keywords + radius ≤ 200.
  3. Wait for finish (watch live %).
  4. Extract Websites if needed.
  5. Start Extraction for emails.
  6. Export CSV and/or Export xlsx filtered.

B) Quick one Maps search

  1. Search on Maps yourself.
  2. Start Monitoring → scroll → Stop.
  3. Extract → Export.

9. Troubleshooting

ProblemTry this
Extension missingLoad unpacked → extension folder
Area Search finds nothingCheck city name; radius ≤ 200; simpler keywords
Email won’t startRun Extract Websites first
Stuck on PauseClick Resume
Chrome feels slowLower Parallel Tabs / Concurrent Requests
Red Errors badgeOften harmless; Clear all after Reload if needed
Excel button failsReload extension; need at least one saved business
